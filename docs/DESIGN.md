# Apifox 助手：设计基线（唯一视觉来源）

版本：1.0（2026-11-07）
适用范围：阶段 D 的原生桌面客户端（F16）及此后所有界面改动。本文是界面视觉的**唯一来源**：界面代码的颜色、字号、间距、圆角只从本文的令牌表取值；改令牌必须同一次改动里更新本文与 `Desktop/Native/UiTokens.cs`，并说明理由。
依据：docs/方案.md §6（设计标准：继承来源与采用规则）、docs/功能清单与验收标准.md"设计验收"D1–D14、docs/DECISIONS/D1-桌面技术栈.md（技术栈与已知代价）。
继承规则：灰阶铬色沿用本产品过渡页（`Web/app.css`）已验证的取值，保持视觉连续；强调色按方案 §6.2 #2 为本产品语境自选，不抄任何兄弟产品色值。

## 1. 原则

1. 灰阶铬色 + 恰一个强调色。强调色只出现在主行动与焦点；无渐变、无玻璃拟态、无阴影、无框架默认观感直接交付。
2. 状态一律"颜色 + 文字"双通道；错误/风险用文字色，不铺大面积色底；灰度打印仍可读。
3. 每屏只有一个实心主按钮；其余 ghost；"停止"类为 ghost + 危险字色且位置尺寸不变。
4. 不可逆或破坏性动作（执行同步、覆盖式写入、退出确认）用原生确认对话框；常规校验内联展示，不弹窗。
5. 空态不留白；失败与截断如实显示；"部分完成""结果不确定"不显示成全部成功。
6. 中文单语；按钮用动词；状态说结果不说机制；错误给下一步；不用空话（赋能/闭环/一站式/无缝/智能…）；不向用户自述工程进度。

## 2. 颜色令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `Bg` | `#F5F7FB` | 窗口背景 |
| `Panel` | `#FFFFFF` | 面板、输入框、列表底色 |
| `Line` | `#E3E8F0` | 1px 发丝边：分隔线、输入框与 ghost 控件描边 |
| `Text` | `#1F2937` | 正文、控件文字 |
| `Muted` | `#6B7280` | 次要说明、标签、禁用文字（禁用另加 50% 不透明度观感由控件态表达，不改色值） |
| `Nav` | `#111827` | 左侧导航底色（深灰铬，延续过渡页） |
| `NavText` | `#E5E7EB` | 导航文字 |
| `NavSelected` | `#1F2937` | 导航选中项底色 |
| **`Accent`** | **`#0B5394`** | 唯一强调色：主按钮填充、焦点环、导航选中标记、进行中进度条。取"墨水蓝"：文档与差异审阅语境要冷静、可长时间注视；与白底对比度 7.8:1（WCAG AA 通过，正文级 AAA 通过）；白字在其上同为 7.8:1。非任何框架默认蓝 |
| `AccentHover` | `#0A4A82` | 主按钮与导航 hover 的加深档（同一色相，只改底色，无位移/缩放/阴影） |
| `OkText` | `#15803D` | 成功/通过状态的**文字**色 |
| `WarnText` | `#B45309` | 警示、待确认、"部分完成"的**文字**色 |
| `BadText` | `#B91C1C` | 错误、失败、阻断、停止按钮的**文字**色 |

规则：语义色只承担状态且不作唯一信号——每个状态同时有文字标签（如"部分完成""已阻断"）。`Ok/Warn/Bad` 只用于文字与细图标，不做大面积底色。禁用控件：`Muted` 文字 + `Line` 描边 + 面板底。

## 3. 字号档（封闭四档）

档位按 96dpi 逻辑像素记录；WinForms 以磅落码，换算 = 像素 × 0.75。不得新增第五档；确需扩档先改本文，严格递增、无死级别、每级有使用点。

| 档 | 像素（磅） | 行高 | 使用点 |
| --- | --- | --- | --- |
| Caption | 12px（9pt） | 18px（行距 1.5） | 辅助说明、表头、状态行、标签 |
| Body | 14px（10.5pt） | 22px（正文行距 1.55） | 正文、输入框、列表行、按钮 |
| Section | 20px（15pt） | 30px | 分区标题、页标题 |
| Title | 28px（21pt） | 40px | 首屏大标题（如空态引导） |

字体栈（有序，找到即停，全不匹配回退系统字体；刻意排除衬线中文字体）：Segoe UI → Microsoft YaHei UI → Microsoft YaHei → SimHei。
等宽栈（计数、进度、ID、路径、差异文本必须等宽）："Cascadia Mono" → Consolas → Courier New → monospace。
中文排版附加条款（审查 D10）：全角标点；行首行尾禁则；正文容器 ≤45em；字距非负；禁假斜体；中文引用只用「」；中英文之间留一个半角空隙。

## 4. 间距（封闭五档，4px 基准）

| 档 | 值 | 语义 |
| --- | --- | --- |
| `Xs` | 4 | 图标与文字、行内元素之间 |
| `Sm` | 8 | 控件组内间距、列表行内边距 |
| `Md` | 12 | 相关联控件之间、面板内边距（紧凑区） |
| `Lg` | 16 | 面板内边距、分区之间 |
| `Xl` | 24 | 页面级留白、分区标题与内容之间 |

组件内不得出现档外数值；表格密集屏确需扩档先改本文。

## 5. 形状与描边

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| 圆角·控件 | 4px | 按钮、输入框（WinForms 首版方角，见 §8 实现差距） |
| 圆角·容器 | 8px | 面板卡（嵌套圆角内 = 外 − pad） |
| 边框 | 1px `Line` | 发丝边；浮层之外不投影、不发光 |

## 6. 控件形态

| 控件 | 形态 |
| --- | --- |
| 主按钮（每屏至多一个） | `Accent` 实心填充 + 白字，无描边；hover 只改底色（加深一档，无位移/缩放/阴影）；禁用 = `Line` 描边 + `Muted` 字 |
| Ghost 按钮 | `Panel` 底 + 1px `Line` 描边 + `Text` 字；hover 底色变 `Bg` |
| 停止/危险 | Ghost 形态 + `BadText` 字色；位置尺寸与常态一致（防按钮跳位） |
| 导航项 | `Nav` 底上：未选中 `NavText`；选中 `NavSelected` 底 + 白字 + 左侧 3px `Accent` 标记；hover 只改底色 |
| 列表行 | `Panel` 底，行高 ≥ Body 行高 + `Sm`×2；选中行底 `Bg` + 左侧 3px `Accent` 标记（不用系统高亮蓝）——由 `Ui.List` 工厂自绘统一落地（2026-11-07），列表不得绕过工厂创建；程序化恢复选中经 `Ui.SelectItem` 同时恢复焦点标记（Selected + Focused，2026-11-07 第三十三轮）——列表重建后方向键从选中项继续、不跳回首行，程序化选中不得绕过该入口；两个主页面的列表在重建（页面切换、刷新、保存对话框返回）后按既有选中恢复，任务页自第一轮起如此，项目配置页补齐于第三十四轮（此前任何重建后选中丢失、「编辑/连接与写入探测」退回禁用）；列宽：标识列（首列）吸收剩余可视宽度（`ListColumns` 单一口径，2026-11-07 第三十七轮）——列合计对齐可视宽度，正常窗口宽度不出横向滚动条（此前固定像素列宽合计 872/880px，默认窗口下「更新时间」等列尾列被横向滚动条藏住）；窗口放不下固定列合计时首列回退设计宽度、横向滚动条如实出现；任务页列表与详情的分割（2026-11-07 第三十八轮）：详情区保持 420 设计宽（`FixedPanel = Panel2`），窗口缩放时列表吸收剩余宽度——与标识列吸收剩余可视宽度同一方向（FixedPanel 缺省 None 会让详情区随窗口按比例放大、偏离设计宽）；分割距离在首次显示时按可行性门控设置（详情设计宽 + 列表下限 + 分隔条宽），壳最小窗口宽度（分割面板约 776px）下同样成立，不停留在 WinForms 默认的 50px（此前门控「宽度 > 800」在此恒假，任务列表只剩一条缝）；双击激活（2026-11-08 第三十九轮）：双击只在命中行时打开该行（`Ui.ActivateItem` 唯一入口，MouseDoubleClick + HitTest 守卫）——`ListView.DoubleClick` 不区分命中行，双击空白区不动作（此前配置列表双击空白区会借清空后的空选中打开「新建配置」对话框） |
| 输入框 | `Panel` 底 + 1px `Line`；聚焦描边 `Accent`；校验失败内联 `BadText` 文字 + 描边 `BadText`，不弹窗——由 `Ui.Input`/`Ui.Field` 工厂统一落地（2026-11-07：发丝边、聚焦描边与校验失败描边；失败字段按 `UserException.Field` 定位，覆盖共享解析口径的三个配置对话框与配置对话框外层「保存」的核心字段，范围与挂账见 §8），输入框不得绕过工厂创建（字段与属性两种声明形式都在机械检查内）；多行输入 Enter 换行、不触发对话框主按钮（`AcceptsReturn` 由工厂统一设置，2026-11-07 第三十五轮——窗体设了 AcceptButton 时未设该属性的多行输入会把 Enter 交给主按钮，「每行一条」的输入无法换行） |
| 状态行 | 固定占位（文案变化不推动布局）；进行中可含进度条（`Accent` 填充） |
| 长内容区 | 内容可能超出可视高度的宿主一律用 `Ui.ScrollHost` 工厂（`AutoScroll` 面板；任务详情、补充说明编辑区、配置编辑对话框、新建任务对话框与「模型服务/模块与模板/序列化与分析」三个配置子对话框共用）；子项多为不接收焦点的标签，点击内容任意处把焦点交给宿主后滚轮可滚动（取焦对子树递归代挂，按钮与输入框自带焦点不代劳）；不是 Tab 停靠点。滚动条拖动与点击取焦为确定行为，滚轮悬停滚动与键盘滚动随 G-D5 真机复核 |
| 菜单/快捷键 | 原生 MenuStrip；按钮次序按 Windows 惯例（主行动在右）；对话框 Enter=确认、Esc=取消；壳级快捷键只取 Windows 惯例手势——Ctrl+1/Ctrl+2 切页、F5 刷新当前页、F1 帮助（本工具为「关于」），不占编辑键、不给「退出」与目录项发明手势——由 `Desktop/Native/ShellShortcuts` 单一口径登记（2026-11-07 第二十九轮），界面代码不得就地写手势 |

## 7. 状态表模板（每屏必交）

每屏按此表逐态定义控件可用性与文案；空态不留白，失败不装干净。

| 态 | 要求 |
| --- | --- |
| 空态 | 说明"现在有什么可做"+ 唯一行动按钮 |
| 加载 | 状态行文案 + 主行动禁用 |
| 执行中 | 进度 + 可取消（停止为 ghost + 危险字色）；主行动隐藏或禁用 |
| 错误 | `BadText` 文字 + 下一步指引；不铺色底 |
| 禁用 | 控件禁用 + 一句话说明缺什么 |
| 部分完成/中断 | `WarnText` 标签 + 如实数字，不显示成全部成功 |

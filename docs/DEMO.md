# 3 分钟演示：从零到「看到差异被同步」

这一页是**演示剧本**，不是新功能说明。它只做一件事：把主链路按 `README.md`「使用流程」已有的那几站串成一条 3 分钟能走完的路，
让第一次看这个工具的人在三分钟内看到**工具自己找出来的两处差异**，而不是听人念功能清单。

**演示不执行远端写入，只到同步预览。** 这是 `docs/方案.md` §8 那条写入安全不变量在演示路径上的落点：
演示现场不连 Apifox、不写任何远端资源，最后停在「同步预览」那一屏，把「会写什么」摆出来给人看。

## 演示前的一次性准备

1. 打开桌面客户端（`dotnet run --project ApifoxHelper.csproj`，或已发布的 `ApifoxHelper.exe`）。
2. 演示工作区在仓库里：`samples/demo-workspace/`。它只有四个文件——
   `Demo.Api.csproj`、`Controllers/OrdersController.cs`、`Models/OrderSummary.cs`、`apifox-remote.json`。
   没有 `bin/`、没有 `obj/`、没有任务目录：**从零开始**，不是某台机器上的残留。
3. 演示工作区里**故意留了两处差异**，这就是演示要展示的东西：
   - **缺口 ①**：`OrdersController.ListOrders` 没有 `///` 注释（`GetOrder` 有，对照着看）。
   - **缺口 ②**：`OrderSummary.TotalAmount` 的源码注释写「单位：元」，而 `apifox-remote.json` 里同一字段写「单位：分」。
4. 远端不用连：`apifox-remote.json` 是一份 OpenAPI 快照，演示时经「导入离线远端 JSON」读入，走的是产品已有的离线路径。

## 演示表

每一站的「对应 README 使用流程」一格指向 `README.md`「使用流程」里已有的那一条——**演示不新增步骤**。

| 站 | 演示动作 | 对应 README 使用流程 | 3 分钟内看到什么 |
| --- | --- | --- | --- |
| 1 | 项目设置里把仓库根目录指到 `samples/demo-workspace`，API 项目选 `Demo.Api.csproj`，保存 | 第 1 条「项目设置」 | 保存后自动核对，状态行说清这一份配置读到了什么 |
| 2 | 检查任务页「新建任务」→ 选配置 → 「创建并扫描」 | 第 2 条「检查任务」 | 扫描在后台跑，进度与当前接口名一路可见，不需要 build/restore |
| 3 | 源码注释页看注释缺口清单 | 第 3 条「源码注释」 | **缺口 ①**：`ListOrders` 被工具自己报成「缺说明」，`GetOrder` 是完整的——不用人翻代码 |
| 4 | 「生成草稿」→ 规则提取 → 逐条「接受并下一条」 | 第 3 条「源码注释」 | 候选带着代码证据出现；不配模型服务也有候选，这一站不联网 |
| 5 | 注释补丁页生成计划 → 确认后回写源码 | 第 4 条「注释补丁」 | 只改 `///` 注释行；回写后清单逐文件列出改了哪一处 |
| 6 | 回到检查任务页「导入离线远端 JSON」→ 选 `apifox-remote.json` → 开始检查 | 第 7 条「Apifox 差异」 | **缺口 ②**：`TotalAmount` 的说明冲突被逐项列出来，源码说「元」、远端说「分」 |
| 7 | 差异确认页逐项确认 → 生成同步预览（**不执行写入**） | 第 8 条「同步」 | 预览里能看到「会写什么」，写入按钮不按——演示到此为止 |

## 演示时要说清的三句话

- **这两处差异是工具找出来的，不是我准备好的**：缺口 ① 由扫描器报出（`SourceScanService` 的注释位置清单），
  缺口 ② 由检查把源码注释与远端快照的同一字段摆在一起比出来。
- **不配模型服务也能走完**：第 4 站用的是规则提取，第 6 站用的是离线快照——整条演示不联网、不调模型服务。
- **演示停在同步预览**：写入远端默认关闭，演示现场不执行写入，也不连 Apifox。

## 证据口径（如实写在这里）

- 这一页在 Linux 容器里按 wine 10.0 + Xvfb **模拟器**走过一遍，截图归档在 `docs/evidence/demo-run/`。
  **模拟器读数不是 Windows 真机结果**——与 `README.md`「已知限制」第 1 条同一口径，真机仍 0 台。
- 演示工作区那两处缺口由 `ApifoxHelper.Tests/DemoWorkspaceTests.cs` 机械钉住：测试里真的跑一遍
  `ProjectLoader` → `EndpointDiscovery` → `SlotScanner`，扫不出来即红；剧本每一站与 `README.md`「使用流程」的
  对账也在同一份测试里。**这一页改了而 README 没跟着改，测试会红。**
